Methodology and verification standards

  • Prefer official vendor API and authentication documentation.
  • Distinguish vendor-maintained MCP servers from community projects.
  • Do not interpret blocked pages or missing search results as proof that an API or MCP does not exist.
  • Access may depend on plan, region, account type, tenant settings or administrator permissions.
  • Only report accuracy metrics after creating a valid manually labelled test set and comparing predictions against it.
